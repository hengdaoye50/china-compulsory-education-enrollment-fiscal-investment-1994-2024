# 全国小学与初中早期财政性教育经费重建

2026年10月11日。原始文件和既有原值表均保留。本目录新增1994—2024年62条分学段记录，每条记录区分支出、收入、组成项重建和模型估算。研究主体仍为1995—2024年30年；1994年作为前置估算补充，不将整个研究改称30个年份的1994—2024年研究。

## 2006年金额单位

先按千元代入。小学财政性收入1990.06669亿元，初中1171.43310亿元；较2005年分别增加19.2343%、19.5006%。财政性收入占比为86.5597%、80.9472%，均小于100%，金额低于同学段收入总额，组成项之和与原表总额相符。这些属于合理性检查，单靠它们不能证明单位。

进一步核对国家统计局《中国统计年鉴2012》20-39表（单位万元）：2006年全国总额98153087万元、财政性经费63483648万元、预算内经费57956138万元。当地年鉴全国分学段总表对应原值981530865、634836475、579561380。按千元换算，前两项仅差5千元，预算内经费完全一致；差额与整万元四舍五入一致。单位据此由待核提升为“外部总量交叉核实为千元”，恢复绘图金额。原始unit_pending标记仍保留，解决记录单列于unit_resolution_2006.json。

## 1995—1997年：按支出来源重建

这一时期全国总表标题为“全国教育经费总支出”，不能把同卷部门收入表的加总冒充同口径全国财政性收入。重建采用互不重复的支出来源：

`财政性支出F = 预算内支出B + 教育税费支出 + 企业办学校支出 + 校办产业等用于教育的支出 + 其他财政性支出`

`经费总支出T = F + 社会团体及公民个人办学支出 + 社会捐集资支出 + 学杂费支出 + 其他教育经费支出`

预算内支出取预算表的“银行支出数”加教育基建支出、预算内专项资金及其他支出。不采用包括其他来源抵预算部分的“实际支出总计”，避免重复计入。对应同卷全国表1-3的C、Q、R列，税费表1-8的B列，企业表1-11的G列，产业及其他财政性表1-14的B、H列；非财政性部分来自表1-17的G列及表1-18的B、H、N列。原始表及各行留存在source_evidence.json。

三年全国财政性支出与总支出均精确复原，差额为0。另用国家统计局1999年鉴20-37表核对1997年：普通小学财政性经费6378759万元、初级中学4166759万元；本研究结果分别为63787594千元、41667585千元，符合整数万元的舍入精度。

来源：https://www.stats.gov.cn/yearbook/1999/t37c.htm

## 1998—2004年：按收入来源重建

部门表之外另列企业及民办学校，因此全国同学段总额应合并三类学校：

`总收入T = 部门所属学校总收入 + 企业办学校总收入 + 社会团体及公民个人办学总收入`

`财政性收入F = 部门事业性预算拨款 + 部门基建拨款 + 部门教育附加拨款 + 部门校办产业等用于教育收入 + 企业财政性部分`

企业部分不是所有年份都取同一列。1998—2001年，全国总表将企业办学校总收入计入财政性经费；2002—2004年则计企业拨款与企业学校校办产业等用于教育收入。逐年选择规则不是由图形是否平滑决定，而是由全国总表的来源项及金额约束决定。后一规则延用至2005—2006年，并精确复原已公布的分学段财政性收入和总收入。

1998—2004年每年的全国财政性收入、总收入重建差额均为0；2005—2006年的全国、普通小学、初级中学两项桥接差额也均为0。由此，早期记录的新增值主要是对实际观察组成项的会计重建，而非统计插值。全国核对保证组成项合并与当年总表一致，并不自动证明不同年代的学校类型完全对应。

## 1994年：明确标示的分配比例回推

当前没有取得1994年完整的分学段来源表。采用官方全国财政性支出11747395.6万元、总经费14887812.6万元作为锚点，以1995年同学段支出占全国相应支出的比例回推：

`估计F(s,1994) = 全国F(1994) × F(s,1995) / 全国F(1995)`

`估计T(s,1994) = 全国T(1994) × T(s,1995) / 全国T(1995)`

F和T分别回推，随后计算F/T。假设是1994、1995年学段分配比例相近，不是声称学段增速相同的已知事实。两学段之外的余额仍留给其他教育类别，不将全国总额全部分给义务教育。

来源（保留一位万元小数，减少锚点舍入）：https://www.stats.gov.cn/sj/ndsj/2001c/t2036c.htm

情景范围将1995、1996、1997年实际学段分配比例分别用于1994年同一锚点，取最小和最大金额；比例范围用F最小/T最大、F最大/T最小形成外包范围。这只是附近年份分配假设的敏感性结果，不是置信区间，也不涵盖1994年结构突变、学校类型不一致等误差。1994年仅显示空心估算点和情景范围，不与1995年直接连线。

用1996年分配比例回推1995年、1997年分配比例回推1996年，各学段各指标只有两个回测。小学财政性金额误差为+0.92%、−0.31%，初中为+3.19%、−1.50%；总额最大绝对误差为3.47%。样本很少，不能据此宣称1994年估计误差小于该幅度。回测明细见backcast_validation.csv。

另检索到外交部转载《中国的儿童状况》称1994年“小学教育经费达594亿元”。这一金额高于本方法总额暂估505.37亿元，提示1994年分配比例可能变化，或材料的学校、经费范围存在差异。该材料没有分列财政性来源，不能直接替换财政性金额。本研究保留此项外部不一致，并将1994年标为暂估；它不能充当趋势转折或精确同比结论的依据。必须取得原始分学段表及范围说明，才能升级为观察值。情景范围不能被解释为已包含这一外部差异。

## 长时段图与结论边界

图2改为“全国小学与初中财政性教育经费及其占比（1994—2024年）”。早期支出与后期收入都保留，并在1998年断线；2002年企业经费计入方式变化、2007年民办经费定义变化处也断线。1994年的空心点为模型暂估，不补成原始观察值。2006年经过外部核实恢复为观察值。

2007年的民办办学经费由总经费改为举办者投入，影响占比分母；这一变化见国家统计局20-39表脚注。断线表示比较边界，不是缺失记录。1998年初中重建金额较1997年支出低，不能解释为当年财政投入实际下降。长期描述应分别讨论各统计制度下的水平与变化，不计算跨上述边界的无条件同比或31年同口径复合增速。
