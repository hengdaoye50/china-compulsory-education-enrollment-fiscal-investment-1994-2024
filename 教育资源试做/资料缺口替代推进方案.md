# 资料缺口的替代推进方案（2026年10月7日）

用户确认没有具体原页及完整填报规则，且知网年鉴数据库不收录该年鉴。取消知网作为本项目已确认的获取入口，不再要求用户重复尝试。以下是可审阅的推进方案；尚未执行新研究设计、模型或可视化，主体面板仍不变。

## 1. 推荐路线：保留原问题，减少对财政学生分母的依赖

以省级、普通小学和普通初中为对象，继续核准2017—2023实际支出总额及个人、公用、基建组成。研究可先回答：学生规模变化时，教师、班级、学校和实际支出是否呈现不同调整轨迹；哪些省份出现学生减少与投入总额保持/上升并存。先描述各条序列，符合覆盖条件的部分再比较变化方向和速度，不自动解释为低效、刚性机制或因果效应。

此路线不需要把实际支出除以财政学生数，因此不用等待财政加权分母。现有31省×7年×2学段支出候选仍须完成年度范围与整理版质量检查，不能因为绕开分母而豁免这些核查。自然年支出是流量，教育学生/教师等是统计时点存量；即使并列指数或增长率，也明确各自时间与举办者范围。政府举办者财政指标和所有举办者资源指标不能据省名和年份直接解释为同一对象的人均机制。

公布的生均指标可另作已发布指标描述，保留原定义与发布版本。暂不做“生均增加有多少来自学生减少”的恒等分解、不制造财政学生数；适龄人口和在校生也不互代。需要货币跨年比较时，另明确价格调整方案，不能把名义增长当真实资源增长。

相比原先设想，减少的是精确生均归因能力，保留的是人口/生源变化与资源、实际投入调整这一主线。此处是建议，未自动修改最终研究设计。

## 2. 原页缺口：逐项隔离而非整套停用

2017新疆地方小学事业费生均差0.01元：官方公告值11738.70可继续用于原公告序列，年鉴11738.71保留在其独立候选序列并标差异。不得默认为修订、静默替换或据此否定所有直接支出金额。

2017贵州普通初中财政补助E31字符串“.4470162”：细项不进入需要该值的构成计算。原B/C/G/L合计、个人、公用、基建与相邻地方表核查证据仍保留，不能将猜测修复值当作原数，也不需要删除整个省年或2017年度。一般预算第6部分并未出现该细项异常。

缺原出版社页时，可使用整理版作为明确披露的二手数据，通过公布指标、表内组成、省合计、相邻口径与另一转录渠道开展多来源核查。867个生均一致仅验证这些生均单元格对应，不等于其余支出表已经逐格获得原版认证。同源转载不算独立来源。必要时可对受影响具体指标进行剔除敏感性检查，不预先删掉全部相关观察。

## 4. 后续工作与限度

可以继续做：候选金额的资金层级与隶属关系校验、年度说明与目录核准、举办者范围桥接、官方生均序列核对、适龄人口来源与地域重分类核查。原页、完整规则和直接财政学生数保持可补则补，不再设为全部研究开始的硬条件。

不能用便宜的代用品补出缺失证据：学生年初年末取简单平均、套高校或其他成本监审权重、实际总额除生均倒推分母、事业年末学生乘生均推总额，均不能充当已经核准的财政学生/支出。若未来研究确实需要估计分母，应另提出有证据的假设和敏感性范围，并与官方原值区别，本方案未授权或执行这种重构。
