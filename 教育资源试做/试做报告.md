# 人口变化下的教育资源与财政投入调整：第一轮数据试做

核验日期：2026年10月4日。按《选题试做交接_教育资源与财政投入.md》的顺序，先获取原件、核查口径与建立样本，再开展描述分析。未修改原始统计值以迎合假设。

## 结论与选题判断

最新分析进度：第30节补充已有16个资源时间模型的省份聚类推断、区间、多重检验校正和系数比较；第29节已完成四篇C刊重点述评，第27/26节为人口核查和持续下降分析。资源回归已有模型条件下的统计推断，仍非因果识别；适龄人口连续序列未完成。当前无需等待完整财政分母开展全部研究，仍不进行精确生均分解或更新图表。开篇第一轮收窄建议与数据状态是历史记录，以后续章节和最新交接为准。

**建议继续，但收窄为“生源变化下，师资与班级的调整路径及学段差异”。** 已建立2013—2024年31个省级地区、两个学段的744条省—年—学段观察，另有24条全国观察。学生、招生、专任教师、班级四个核心字段无缺失，分省合计逐年与官方全国数一致。财政部分能展示已发布生均指标的变化与关联，目前不足以分解财政总投入，也不足以判断财政压力造成了怎样的调整。

2024年全国小学在校生同比减少2.32%，专任教师减少0.99%，班级减少3.35%。师资数量下降较缓，班级下降较快，不能据此说“资源均滞后于生源”。初中在校生仍增长2.72%，教师增长1.61%，班级增长2.07%，与小学方向不同。省级结果不能推导县域、学校的闲置、通学距离或质量变化。

六幅交互图依次回答全国变化、地区同步性、增长与收缩阶段、师资密度分解、生均经费关联和财力结构关联。可切换小学/初中、教师/班级；图表来源菜单提供底表和原始链接。离线入口为本目录的《教育资源试做.html》。

## 2. 最小样本与变量口径

主表：`data/education_resource_panel.csv`。键为 `year + province + stage`；`primary`=小学阶段，`junior`=初中阶段；`全国`必须从省级统计分析中剔除，不能作为第32个地区。2013年为资源面板基期，2014—2024年才有面板内同比。经费附列存在缺失和断点，不意味着744条记录都构成经费平衡面板。空值表示缺失/未提供，不表示零。

| 字段 | 单位与含义 | 使用约束 |
|---|---|---|
| students | 人，在校生 | 当前服务负荷代理，不称适龄人口 |
| entrants / graduates | 人，招生/毕业生 | 流量，不能与在校生相互替代 |
| teachers | 人，学段专任教师 | 不使用“普通小学学校教职工”代替；不是全体工作人员 |
| classes | 个，对应学段班级 | 与学生、学段教师共同作为资源指标；不等于校点数 |
| schools / teaching_sites | 所，普通学校/小学教学点 | 学校数覆盖与学段学生不同；不计算“学生÷普通学校” |
| pupils_per_teacher / teachers_per_100_students | 学生/教师；教师/100学生 | 数量比例，不代表教学质量；用学段口径计算 |
| pupils_per_class | 人/班 | 省级总体平均，不是学校班额分布或超大班额比例 |
| *_growth_pct | %，100×(本年/上年−1) | 对应资源面板内连续年份 |
| demand_phase | 学生同比正/负的描述分组 | “增长/收缩”仅指年度生源方向，不判定长期人口转折 |
| budget_per_student | 元/生，生均一般公共预算教育经费 | 名义值；2017—2023分学段可取得，2021有同口径断点 |
| career_per_student / public_per_student | 元/生，教育事业费/公用经费 | 两类不是互斥分类，不能相加或推算“人员费” |
| regional_budget_education_100m | 亿元，全地区一般公共预算教育经费 | 全学段地区总额，不能当小学或初中总投入 |
| education_budget_share_pct | %，公告所列教育经费占一般公共预算支出比重 | 保留公告口径，不替代其他财政统计分类 |
| revenue_100m / expenditure_100m | 亿元，地方一般公共预算收入/支出 | 2024全地区层级；非省本级；未识别转移支付 |
| revenue_expenditure_ratio | 收入/支出，无量纲 | 图中乘100显示%；财力结构代理，不命名为真实财政压力 |
| nbs_education_expenditure_100m | 亿元，统计局教育功能支出 | 仅供财政口径核查，不与教育部经费值互换 |
| *_source / source | 官方URL | 原值可回溯到原件、附件和表头映射 |

教育部小学学段学生与专任教师包括普通小学、教学点、一贯制小学段及附设班等。初中亦按相应学段覆盖，部分统计包括职业初中。因而图中“小学/初中”是学段简称，不能解释成仅独立普通学校。逐年表头映射存于 `data/resource_schemas.json`；逐字段值、原文、列索引和文件位置存于 `data/resource_cells.csv`。尤其2021起小学学生表学前教育列扩展，已按每年表头调整在校生列，而非固定列号抓取。

## 3. 核验结果、断点与未解异常

- 核心资源键唯一、744条省级观察覆盖完整，四个核心字段无缺失。分省之和与全国数的对账见 `validation_totals.csv`，核心字段差值均为零。
- 2013年国家统计局小学表与教育部32个地域、五项指标（学校、学段教师、毕业、招生、在校生）的160个数值全部一致，见 `validation_nbs2013.csv`。另对2024小学全国及北京、福建、河南、广东、新疆的学生、教师进行年鉴图片抽查，均一致，见 `validation_cross_source.csv`。这不是全部省份、全部字段的独立复核。
- 2024财政图片人工转录后，31地区支出合计与表头完全一致；收入合计差0.01亿元、教育功能支出合计差0.02亿元，属末位四舍五入量级。原图为[地方收入](https://www.stats.gov.cn/sj/ndsj/2025/html/C07-05.jpg)、[地方支出](https://www.stats.gov.cn/sj/ndsj/2025/html/C07-06.jpg)。财政转录未宣称双人独立录入。
- 对2021—2022和2022—2023两个区间，32地域×两学段×三类生均经费，共384项同比复算，容差0.015个百分点。2022—2023的192项全部与公告一致。图表限定使用该区间。
- **新疆2021—2022六项复算与官方增速存在差异，保留未解。** 小学/初中生均预算复算为0.1243%/−0.0507%，公告为0.14%/0.04%；事业费复算0.4990%/0.4641%，公告0.53%/0.59%；公用费复算−16.9365%/−6.3316%，公告−16.59%/−5.57%。现有公告未说明原因，不据其他统计的兵团口径注释强行归因；原值和官方增速均保留在 `finance_long.csv`，异常见 `validation_finance_growth.csv`。
- 2021年经费公告依据国发〔2021〕5号作部分指标“同口径”比较。未用2020—2021原值变化替代官方同口径增长。
- 2024经费附件改为全学段汇总，不能把其生均值接到小学/初中序列。经费分母与事业统计学生的完整一致性尚未确认，禁止“生均×学生”还原分学段总经费。
- 本轮财政分析为名义金额，未做价格平减；学校数不用于校均规模。旧表教职工与学段教师覆盖不同，出现前者小于后者也不能直接认定统计错误。

## 4. 探索性发现

### 最新一年显示资源与学段的差异

| 2024同比 | 小学 | 初中 |
|---|---:|---:|
| 在校生 | −2.32% | +2.72% |
| 招生 | −13.91% | +5.36% |
| 专任教师 | −0.99% | +1.61% |
| 班级 | −3.35% | +2.07% |
| 每百学生教师数 | +1.36% | −1.08% |

小学31地区中26个学生减少，其中7个教师增加；这26个地区班级全部减少。初中只有4个地区学生减少，其中2个教师增加、1个班级增加。招生比在校生下降更快，提示新入学规模与存量负荷必须分开观察；不据一年变化预测后续人口路径。

小学师资密度上升不来自教师增加。恒等式为 `100ln[(T1/S1)/(T0/S0)] = 100ln(T1/T0) − 100ln(S1/S0)`。教师数量贡献−1.00个对数点，学生分母贡献+2.35个对数点，合计+1.35个对数点（对应通常同比+1.36%）。这是数量恒等式，不是投入或质量分解；财政分解因缺同口径总投入未实施。

### 增长与收缩阶段存在描述差异，但不足以识别不对称机制

| 学段与生源方向，2014—2024省—年观察 | n | 学生同比中位数 | 教师同比中位数 | 班级同比中位数 |
|---|---:|---:|---:|---:|
| 小学收缩 | 107 | −1.57% | −0.43% | −1.78% |
| 小学增长 | 234 | +2.11% | +2.22% | +1.70% |
| 初中收缩 | 112 | −1.82% | +0.02% | −0.83% |
| 初中增长 | 229 | +3.21% | +2.16% | +3.18% |

剔除2024后，小学收缩期教师同比中位数为−0.14%，增长期为+2.28%；方向差异仍在。仅保留学生变化绝对值≥1%的观察，初中收缩期教师中位数从+0.02%变为−0.22%，所以“初中收缩期教师不减少”不是稳健说法。详见 `sensitivity_phase.csv`。

这些组的省份、年份与变化幅度不同，同一省重复出现。可能受到教师编制与退休、最低配置要求、城乡迁移、学校组织调整、学段队列推进等共同影响；这些是待检验的竞争解释，本轮没有直接机制数据。不能把两组中位数差当作因果调整弹性。

### 财政部分目前只能给出关联

2022—2023年生均预算教育经费与学生变化散点可比较31地区已发布指标，不能区分其变化来自总投入还是经费统计分母。2024地方收入/支出比与教师变化的Pearson相关系数，小学约0.380、初中约0.313；样本均为31。仅为未控制生源与地区结构的同年关联，不能判断财力影响或补助效果，也不据相关系数制定支出政策。

## 5. 下一步最小补充及验收状态

本轮已满足试做的资源样本与可视化验收：取得真实原件和可追溯来源；建立连续两学段样本；完成合计核验与交叉抽查；产生六幅承担解释任务的图；给出收窄题目的依据。**财政总投入分解、连续适龄人口、县校空间配置尚未完成，不能作为现有成果对外声称。**

后续按收益顺序推进：

1. 核实经费生均分母和能否取得同口径小学/初中总投入。若仍缺失，题目将财政限定为背景和已发布生均指标，不承诺投入分解。
2. 利用已保存分类表核查城乡、举办者覆盖与分类断点，优先检验省级平均是否掩盖城乡异向变化。
3. 建立同一地区、相近学生变化幅度的增长/收缩比较，并控制年份与地区差异；先检查幅度和重复观察，不能直接套用因果叙述。
4. 如竞赛需要具体治理应用，选择公开数据较全的一省核实县域校点、通学和教师结构，省级图不包装成学校撤并建议。适龄人口和转移支付仅在真实取到、核验后纳入。

本轮未新增文献综述或声称发现文献空白。研究问题的新颖性仍需针对“资源类型差异、增长/收缩路径与财政约束”查重。

## 10. 第三轮分析：样本构成、影响检查与时间关联（2026年10月6日）

本轮依用户要求只推进数据分析，未新增或更新可视化。原选题“人口变化下的教育资源与财政投入调整”保持不变。资源子问题继续使用在校生年度变化观察生源；财政部分未补齐细表，不新增财政总投入结论。

### 10.1 配对样本有明显的年份和选择构成

小学29对中，22对是增长年在先、收缩年在后；初中35对中，28对是收缩年在先、增长年在后。两学段的时间顺序构成不同，不能把配对分组直接解释为相同条件下两种调整行为。

小学收缩组11/29条观察来自2024年（37.9%），增长组没有2024年观察。初中收缩组22/35条来自2014—2016年（62.9%），增长组16/35条来自2018—2019年（45.7%）。同省配对仍有明显时间构成。

全部达到绝对学生变化≥1%门槛的539条观察中，小学增长183、收缩74；初中增长204、收缩78。配对只保留128条。小学未配对收缩组45条的学生变化中位数为−2.85%、教师−1.89%；配对收缩组29条分别为−1.78%、−0.05%。初中未配对增长组169条的教师中位数为+2.51%，配对增长组35条为+0.80%。这些差异表明配对选中了变化幅度较小、资源表现也不同的观察，不宜向所有收缩或增长地区外推。

### 10.2 逐对比较及省份、年份影响

此前展示的两组中位数分别来自两组观察，不能替代逐对统计。本轮引入一个仅用于描述的计算量：**两期同比有符号和 = 配对增长年的资源同比变化率 + 配对收缩年的资源同比变化率**，单位为百分点。例如+2%和−1%的和为+1个百分点；若收缩年教师仍增加，其增幅也按正值计入。该和不是两年累计增速，也不是因果效应；正值本身不证明调整滞后或错配。

省份等权列先计算每省所含配对的有符号和均值，再对省份取均值；不能与配对中位数混为同一统计量。删除检查保持原配对关系，删除涉及指定省份或年份的整对观察，**不重新配对**。这与上一轮剔除2024年后重新配对的敏感性方案不同。

|学段|资源|逐对有符号和中位数（百分点）|正值配对数/总数|省份等权均值（百分点）|逐省删除后的中位数范围|逐年删除后的中位数范围|
|---|---|---:|---:|---:|---:|---:|
|小学|教师|+2.52|23/29|+2.40|+2.41至+2.76|+1.97至+3.64|
|小学|班级|-0.36|13/29|-0.32|-0.38至+0.06|-0.61至+1.06|

|初中|班级|+1.10|29/35|+1.41|+1.07至+1.10|+0.91至+1.20|

小学教师有符号和的正向描述在逐省、逐年删除后保持，但仍仅适用于原配对样本。小学班级有符号和的符号不稳定：按时间顺序分组，增长在先的22对中位数为−0.63个百分点，收缩在先的7对为+0.63个百分点。不能把“两组班级中位数接近相反数”进一步写成稳定的对称调整规律。初中班级的逐对有符号和偏正，仍需结合年级构成与初中生源周期核查解释。

这些范围是删除观察后的敏感性范围，**不是置信区间**。同一省的多对观察不独立，本轮不提供显著性检验。

### 10.3 当年与上年生源变化的条件关联

为减轻配对的年份构成问题，另用完整平衡面板做探索：每学段31省×2015—2024年=310条观察。没有以学生变化正负筛选，因此包括绝对幅度小于1%的观察；2014年仅用于构造上年变化，2024年无需未来数据。小学、初中分别估计，教师、班级分别作为被解释变量。

模型为：资源对数变化 = 省份固定项 + 年份固定项 + β当年×学生当年对数变化 + β上年×学生上年对数变化 + 残差。各变量采用100×ln（本年/上年）；省份固定项控制资源增速中不随年份变化的省份差异，年份固定项控制同一学段全国共同的年度变化。它们不消除省内随时间变化的城乡、举办者、政策和资源基数差异，也不解决生源与资源同时变化的内生性。

|学段|资源|观察数|当年生源系数|上年生源系数|去除省份、年份均值后的R²|
|---|---|---:|---:|---:|---:|
|小学|教师|310|0.124|0.211|0.104|
|小学|班级|310|0.616|0.151|0.505|
|初中|教师|310|0.082|0.166|0.142|
|初中|班级|310|0.626|0.130|0.701|

系数表示控制上述变量后的对数变化关联斜率。例如小学班级当年系数0.616，表示该模型中当年学生对数变化多1个单位时，班级对数变化的拟合差异为0.616个单位；不能解释为学生变化造成班级变化的效应。表中R²只针对去除省份、年份均值后的变化，不能称为整个资源规模的解释率。

四项主模型中，当年与上年学生变化在去除固定项后仍相关（小学0.593、初中0.602）。两个生源系数不能当作彼此无关的独立过程。逐省删除共124次重估，所有当年、上年系数维持正值；剔除2024年后班级当年系数分别为0.603、0.600，与主模型接近。

教师上年系数在主样本中高于当年，但该排序不稳定：小学2015—2019年当年−0.173、上年+0.248；2020—2024年当年+0.288、上年+0.114。初中2015—2019年当年0.148、上年0.118，也未保持上年更高。2015—2019与2020—2024只是等长时间窗敏感性划分，不被当作已证实的政策断点。本轮因此仅保留“教师与生源的时间关联值得继续检查”，不认定“教师调整滞后一年”。

班级当年系数在两个等长时段均为正，且均高于上年系数；对样本期与单省删除较稳定。教师模型去除固定项后的R²低于班级模型，但仍不能将较低关联直接等同于低效率。

### 10.4 下一年观察不能直接当作迟滞证据

方向转换底表使用2014—2023年、初始学生绝对变化≥1%的观察，并读取其下一年资源与学生变化。下一年学生变化被明确分为增长（≥1%）、收缩（≤−1%）或近零（绝对变化小于1%），避免把下一年资源减少都归因于起始收缩。

在连续两个年度学生均收缩的观察中，小学30条的教师中位数从起始年−1.32%到次年−1.94%，班级从−2.24%到−3.61%；同期学生中位数也从−2.54%到−2.92%。初中43条教师中位数从−0.05%到−0.60%，学生也连续下降（−3.43%、−3.41%）。这些变化可以提出后续核查问题，但不能区分前期调整、当期生源变化与共同趋势；省份与年份有重复，亦不是独立事件样本。

尤其需要区分“学校组织”与“教育学段”口径。2024年[小学学校教职工表](https://hudong.moe.gov.cn/jyb_sjzl/moe_560/2024/quanguo/202603/t20260319_1431397.html)的专任教师为5,721,258人；[小学教育专任教师表](https://hudong.moe.gov.cn/jyb_sjzl/moe_560/2024/quanguo/202603/t20260319_1431395.html)为6,590,072人，后者与现有省级面板全国数一致。前一表的举办者分类不能直接充当现有小学教师口径的分类。现有[中学学校教职工表](https://hudong.moe.gov.cn/jyb_sjzl/moe_560/2024/quanguo/202603/t20260317_1431114.html)的专任教师7,408,090人覆盖多种中学组织形式，也不能充当初中教师总数4,148,831人的分类。不能用学生、班级分类的可得性，推定教师举办者分类已同口径齐全。

### 11.3 两条可行路径及建议

**路径A（建议优先）：省级年级结构与资源变化。** 沿用现有省级研究对象和2013—2024年窗口，先检验各年级人数变化如何构成总在校生变化，再比较一年级与高年级的变化与教师、班级变化的关系。年级人数不等于该年招生人数，两者分别保留；年级间、跨年差额也不能直接解释为净迁移或留存率。空白字段可先采用完整记录方案，并另列算术残差与空白敏感性，填零规则需有明确依据，不预先写入模型。若四年级或六年级缺失使特定地区不进入分年级比较，应披露选择影响。

该路径能继续处理“同样总生源变化，内部年级结构是否不同”这一子问题，保留省际比较基础；仍不直接测量适龄人口、县校空间配置或财政总投入。拟按算术构成检查、样本覆盖、条件关联三步推进，不预先将年级构成认作调整原因。

**路径B：全国城乡分类优先，并分别核查举办者。** 先建立各年分类定义和可比范围，验证同口径学生、班级、学段教师总量，再考察分类变化是否掩盖全国总量内部的差异。无法验证教师举办者覆盖的年份或表型不做三指标联合比较。该路径需要改用全国分类作为补充观察层级，不能回答哪些省的城乡资源如何调整，也不能将类别人数变化直接解释为人口迁移；分类重划可能改变统计数。

建议先A，因年级字段已经完成与省级面板的衔接，较少改变已有分析层级。B可在用户选择后作为补充，不能用它替代省级机制分析。**本轮停在此节点，等待用户选择A或B（或调整问题）后再开展对应结构分析；不因等待期间无回复而自行选路。**

## 12. 年级结构分析结果与第二个待决策节点（2026年10月6日）

用户已授权沿第11节路径A继续。本轮完成年级贡献、总量模型与结构模型的同样本比较、完整年级敏感性和逐省影响检查，未新增可视化。原选题不变。下文区分算术构成与解释模型的增益，不把二者等同。

### 12.1 无需填补空白的主分解

定义一年级学生为原表一年级在校生，非一年级学生为同口径总在校生减一年级人数。后者是由两个已发布总量计算的合计，不是把空白四年级或六年级填零，也不分别推定空白年级人数。班级作相同分解；小学“其余班级”明确包含复式班，不把它等同于二至六年级单年级班数。

年度变化贡献（百分点）=100×本类别本年与上年人数之差÷上年本学段总人数。两类贡献之和精确等于总人数同比，班级使用上年本学段总班数作分母。两类贡献共用分母，可相加；不是各类别自身的增长率，也不是对总量变化的因果贡献。

2014—2024年31省两学段的682条年度观察均可作该分解，另有22条全国年度观察。全部704条学生、班级分解的恒等式核验通过。逐年级分解另保留空白：小学学生338/341条、班级308/341条，初中学生267/341条、班级271/341条具有完整相邻两年字段；不完整观察仅不作全等级求和，仍可进入一年级与总量剩余的主分解。

|学段|指标|2024年总量变化（%）|一年级贡献（百分点）|其余部分贡献（百分点）|
|---|---|---:|---:|---:|
|小学|在校生|-2.322|-2.409|+0.086|
|小学|班级|-3.350|-2.178|-1.172|
|初中|在校生|+2.717|+1.799|+0.918|
|初中|班级|+2.069|+1.444|+0.625|

小学在校生总量减少，但非一年级学生合计略增，说明总量方向不能代表所有年级。2024年小学26个学生总量下降地区中，12个非一年级学生合计增加、14个减少；31个地区一年级学生均减少。初中27个总量增长地区中，23个一年级与其余年级同时增加，4个一年级增加而其余合计减少；4个总量下降地区中，3个一年级仍增加。上述是完整31省的方向统计，不是选择个别案例。

“非一年级合计增加”也不能理解为所有高年级都增加。2024年全国小学二年级贡献+1.616个百分点、六年级+0.020，三至五年级贡献分别为−0.760、−0.212、−0.578，合计抵消后才得到非一年级+0.086个百分点。年级结构具有描述价值，但新入学人数、在校一年级人数和适龄人口仍是不同指标。

### 12.2 一年级区分的增益有限

以2015—2024年每学段31省×10年=310条相同观察比较两个模型：基线包含当年和上年总学生同比、省份固定项、年份固定项；扩展加入当年和上年一年级对总学生变化的贡献。教师、班级同比分别为结果变量。加入一年级贡献但不同时加入其余贡献，避免“总量=一年级+其余”引起完全共线。

本轮统一使用普通同比百分比与算术贡献，第10节用的是对数变化；二者并非同一模型。本轮所有基线与扩展比较使用相同变化定义、样本、固定项和结果变量，不跨第10节的R²作增益比较。

新增系数表示总学生同比相同时，变化更多来自一年级而更少来自其余年级的条件关联，不表示一年级人数的独立因果作用。由于加入变量通常增加样本内R²，同时报告扣除模型自由度的调整后增益。调整后R²按去除固定项后的方差计算，增益单位为R²数值，不是学生或资源增长的百分点，也不是总体规模解释率。

|学段|资源|样本数|样本内R²增益|调整后R²增益|
|---|---|---:|---:|---:|
|小学|教师|310|+0.0051|-0.0017|
|小学|班级|310|+0.0129|+0.0093|
|初中|教师|310|+0.0000|-0.0065|
|初中|班级|310|+0.0012|-0.0011|

小学班级有小幅正向增益，教师及初中两资源的主样本调整后增益为负。分时段后也不呈现统一改善，因此“一年级与其余”的粗分组尚不能承担主要资源解释。

### 12.3 完整年级模型没有消除主要限制

为避免因粗分组过早否定结构作用，使用当年和上年的所有单年级贡献作补充模型，只纳入三个连续年度所需字段均有原值的观察。小学剩306条、初中233条，共539条，排除81条，其中小学4条、初中77条。排除集中于部分早期省—年，不能把完整年级结果直接与主样本31省310条视为同一观察总体。

完整年级贡献之和等于总学生同比，故保留总同比并将小学六年级、初中四年级作为参照，分别只加入其余5个或3个年级的当年和上年贡献。系数是相对参照年级的条件差异，不能将某系数排序写为各年级的治理重要性。基线与扩展仍在完全相同的完整观察上比较。样本不平衡，使用显式省份和年份固定项求解，不使用仅适用于平衡面板的简单双重去均值。

|学段|资源|主样本数|调整后R²增益|剔除2024年后的增益|逐省删除后的增益范围|
|---|---|---:|---:|---:|---:|
|小学|教师|306|+0.0290|+0.0290|-0.0148至+0.0491|

小学班级的附加拟合在逐省删除和剔除2024年后维持正值，是可继续核查的关联线索。小学教师主样本增益为+0.0290，但删除西藏观察后为−0.0148，说明该拟合改善依赖样本构成；这不表示西藏资料错误，也不授权以结果不合预期为由删除它。初中教师调整后增益为负，班级增益接近零且在逐省删除时跨零。

## 13. 年级路径深化：留出检验与教师敏感性（2026年10月6日）

用户在第12节节点明确要求“继续深化”。本轮沿年级路径核验已有结果，不新增可视化。重点从样本内拟合转为留出资源结果的检验，并回查西藏原始数值。结果收紧了第12节对小学班级拟合改善的解释：它是可复核的样本内关联，尚未转化为稳定的留出误差降低。

### 13.1 留出设计的用途和边界

比较已经使用的三种模型：总生源当年/上年变化基线、一年级贡献扩展、完整年级扩展；不挑选新的变量、惩罚参数或“最佳”划分。统一使用完整年级可用样本（小学306条、初中233条），三模型样本、结果、固定项和变化定义完全一致。以省份官方顺序与相邻两年时间块建立五折划分，再按预先设定的第二种偏移规则作敏感性检查。每省的连续两年观察同折，年级字段缺失造成的排除仍保留在此前清单。

每折将约五分之一省—年资源结果留出，其余观察估计省份、年份固定项和生源关联系数；确保训练集仍覆盖全部省份及年份。每条入选观察在每种划分、每个模型中恰好被留出一次。训练与留出键不重叠，留出教师/班级结果不参与参数估计。总计180次训练拟合，包括两学段主样本及另行标记的“不含西藏小学”诊断。

这是**给定已观察生源特征的回溯留出检验**，不是未来预测：当年与上年学生数据已知，训练集可以包含更晚年份，年度共同变化由其他训练省份估计。相邻年级与年份仍相关，误差不独立；两种划分差异不是置信区间。它用于检查附加关联在留出结果中是否保持，不检验政策或人口的因果作用。

RMSE为误差平方均值开方，MAE为绝对误差均值，单位均为资源同比变化的百分点。数值越小越好。下表箭头为同样本“总生源基线 → 完整年级模型”；MAE增加列为扩展相对基线的百分比变化，不是资源增长的百分点。省份等权RMSE另保留在底表。

|学段|资源|样本数|划分一RMSE（百分点）|划分二RMSE（百分点）|两划分MAE增加范围|
|---|---|---:|---:|---:|---:|
|小学|教师|306|1.562 → 1.591|1.567 → 1.596|3.83%至4.19%|
|小学|班级|306|1.232 → 1.238|1.267 → 1.270|4.39%至4.48%|
|初中|教师|233|1.572 → 1.625|1.538 → 1.582|1.67%至4.30%|
|初中|班级|233|1.101 → 1.107|1.114 → 1.124|-0.67%至-0.10%|

完整年级模型在两个划分、两个学段、两个资源的主样本中RMSE均高于基线。小学班级RMSE相对增加0.27%—0.47%，MAE增加4.39%—4.48%；小学教师RMSE相对增加约1.82%。不能把这种误差变化解读为资源调整效率变化。初中完整模型的MAE略降但RMSE增大，说明不同损失指标并不统一，仍不支持广泛的附加改善。

一年级简化扩展中，小学班级RMSE相对降低0.44%—0.53%，但MAE增加0.99%—1.12%；其他资源的RMSE没有降低。因此也不据简化扩展的单一指标微降认定其具有稳定增益。全部比较为固定既有模型的诊断，不因结果不利反复重分折或增删变量寻找改善。

### 13.2 教师敏感性：统计集中，不等于全国贡献

在小学完整年级模型中，将基线与扩展的样本内残差平方和之差按省份加总分配。西藏10条观察的残差平方和从102.933降至69.454，减少33.479，占模型全部样本内误差平方和减少的92.91%。各省分配之和已与整体减少数核对。

该百分比只描述**模型样本内拟合改善的集中程度**，不是全国教师增减的份额，也不是年级结构的因果贡献。主分析将省—年变化率作为观察单位，各省不是按学生数或教师数加权；不能把对少数省份的拟合改善写成全国规模解释。部分省份的误差可能反而增加，分配比例也不能当作非负、互斥的政策贡献。

第12节删除西藏后调整后R²增益转负的结果，与这里的统计集中一致。另作不含西藏的留出诊断，完整年级模型小学教师RMSE仍比基线高2.02%—4.33%，小学班级也未降低。这个诊断没有替换主样本，没有从资源主体删除西藏，更没有证明西藏资料错误。

### 13.3 西藏来源回查与尚不能回答的“为什么”

直接读取2013—2024年已保存教育部原表，逐年回查西藏小学学生、教师、班级共36个总量单元格，均与主体面板一致，未发现这36个字段的提取错误。来源列位置、原值、SHA256见 `tibet_primary_source_checks.csv`。该检查覆盖36个总量字段，不能称为全部年级或全部省份的独立复审。

西藏小学教师同比并不平滑：2017年−3.11%，2018年+9.87%，2022年+0.11%，2023年+4.81%；同期学生变化分别+4.04%、+3.56%、+2.75%、+2.10%。数据确认了教师变化与总生源变化的不同步，以及该地区对统计模型的影响；没有确认背后的编制、教师招聘、学制、调动或统计调整原因。不得据此写成已识别的政策机制或将这些年度默认为异常删除。

模型杠杆值和Cook距离另存底表，只用作影响定位，不以经验阈值自动排除观察；因省份、年份固定项也进入设计矩阵，不把高杠杆单独视为数据质量缺陷。

### 13.4 计算核验与结果解释修订

### 14.5 全国资源比值：分类内部变化与学生份额变化

定义每百名学生资源数R=100×资源/学生。全国R等于各类别学生份额w乘以该类别R的加权和。用两端平均权重和平均比值作对称恒等分解：全国R变化=Σ平均w×类别R变化+Σ平均R×学生份额变化。两个项可精确还原总变化，仅为算术分解，不是政策或迁移的因果贡献。

|小学|班级数|-0.02753|-0.00163|-0.02590|
|初中|专任教师数|-0.08385|-0.07354|-0.01031|
|初中|班级数|-0.01372|-0.01252|-0.00120|

## 15. 城乡分类深化：逐年方向、固定构成与财政衔接边界（2026年10月7日）

用户授权在第14节基础上继续分析。共同窗口仍为2018—2024年，两学段、三个按学校所在地汇总的公布类别；不增加模型、不新增可视化、不更换研究对象。重点检验第14节结论是否依赖最新一年，并区分不同期间及构成控制下的比值变化。

### 15.1 城区小学持续增长、乡村小学持续收缩，初中不能简单照搬

2018—2023五次年度变化中，城区小学学生、教师、班级每年均增加；乡村小学三者每年均减少。加入2024年后仍是六年均如此。这补充了端点累计比较：两个类别相反的数量方向并非仅由个别年造成。但这是公布类别中的净变化，不能识别真实人员调动或地域重分类。

镇区小学五次变化中学生4次增、1次减；教师5次增，班级4次增、1次减，班级与学生方向一致。乡村初中五次学生变化4次减、1次增，而教师5次减；班级4次减、1次增。这意味着教师、班级、学段仍不能合并为同一种“资源响应”。计数仅说明观察方向，不给统计显著性、调整弹性或滞后年限。

### 15.2 三个类别都提高，全国比值却下降

|年份|全国班级/百名学生变化|城区变化|镇区变化|乡村变化|
|---|---:|---:|---:|---:|
|2019|-0.00493|+0.01064|+0.01390|+0.03603|
|2021|-0.00407|+0.00690|+0.02519|+0.06570|
|2022|-0.00970|+0.00627|+0.01939|+0.05865|

### 25.4 2023省际方向：数量调整与金额调整不同

2023年，7省小学学生同比减少：吉林、新疆、江西、河北、河南、湖南、黑龙江。七省教师和班级也都减少；其中前六省一般预算支出合计经全国CPI调整后增加，黑龙江下降。这里是各自公布范围下的方向同现，不是相同学校的配对响应，不能据此称“全部资源未调整”。

初中7省学生减少：内蒙古、吉林、四川、江西、辽宁、重庆、黑龙江；其中4省一般预算支出CPI调整后增加，3省教师增加，班级均减少。不同学段、资源种类、资金范围必须分别观察，不能用小学方向替代初中。

2018—2023逐年计数已保存12条学段—年份汇总。小学学生减少省数分别4、5、4、10、17、7，不是单调扩大；对应一般预算CPI调整金额增加省数2、3、2、6、11、6。这些是年度观察，不把年度学生下降标为持续人口收缩。

另做72条资金/隶属敏感性记录（6年×2学段×3资金×2隶属）。2023小学7个学生减少省，全来源支出CPI调整后均增加，一般预算为6个；全部隶属与地方隶属的一般预算计数均6。初中相应全来源6、一般预算4，两隶属相同。剔除基建改用事业费时，2023这些计数未改变。财政补助小学全部隶属为6、地方为7，说明资金与隶属选取仍会改变读数，不能宣称所有口径结果完全相同。敏感性不修复学校覆盖差别。

### 25.5 研究主线与可支持结论

当前适合推进的问题是：在不同学段与省份的生源变化中，教师、班级数量与财政支出分别怎样调整，为什么不能用一个资源比值概括全部变化？2023小学省际观察已经显示数量减少与支出增加可以并存；它值得继续核查金额构成、政策和时间安排，但不是低效、财政刚性或因果机制已识别。

研究对象和原题不变，先把数量轨迹、支出轨迹和两者覆盖边界组织成论证，不无限等待财政分母。下一步优先区分一次年度下降与连续下降，核准异常/统计调整和明确政策依据，形成主结论与替代解释；人口与固定地域桥接继续补，不用学校个案代全国省级问题。本轮没有新增模型、图表或政策因果归因。
