# 中国义务教育生源规模与财政投入趋势分析报告（1994—2024）

**Chinese Compulsory Education Enrollment and Fiscal Investment Trends 1994–2024**

本仓库保存见数知势队研究的整理数据、原值账本、核查证据、分析程序、原始计算结果、绘图数据及报告。主体观察期为1995—2024年；1994年为单独标记的条件估算补充基期。研究分析全国生源与财政性收入趋势、地区支出差异、支出结构及省级条件关联。

## 数据状态与研究边界

原值候选账本、核准数据与最终分析输出分别保留。名称中的candidate及原有范围待核标记不代表最终核准。1994年条件估算不进入回归；情景范围不等于置信区间。全国财政性收入与学校全来源支出分别解释；在校生与学校财务覆盖尚未完全对应，不据此计算严格同范围生均支出。回归结果属于探索性条件关联，不能作为政策净效应或独立机制证据。未获支持的假设和敏感性结果亦保留。

## 复核与运行

先创建独立Python环境，按requirements.txt安装依赖。已记录精确版本的核心包已锁定，其余辅助包的跨版本兼容性需由复现者核对。两份较大的原值CSV以无损gzip保存，先运行：

```bash
python tools/verify_release.py
python tools/materialize_data.py
python tools/check_key_findings.py
```

脚本保留原项目的相对目录组织。计算与制图输入位于仓库内；原表抽取还需依来源记录补齐外部原件。可按研究阶段查看：

```bash
python 教育资源试做/scripts/deepen_quantitative_analysis.py
python 教育资源试做/scripts/check_component_regime_sensitivity.py
python 教育资源试做/scripts/build_revised_figures.py
```

上述分析程序包含9999次自助检验，可能运行较久并重新写入阶段输出。制图脚本原环境使用Windows微软雅黑C:/Windows/Fonts/msyh.ttc；其他系统需要将字体路径替换为合法可用的中文字体。历史文档修订脚本需要本地报告底稿，已移除个人绝对路径，不能直接作为跨平台生成入口。图表和Word到PDF转换的字体与分页也受环境影响。

发布核验验证文件完整性、压缩恢复、表格结构及关键结果对应；不能把发布核验等同于在全新机器上完成原始年鉴至报告的全流程复跑。统计方法和阶段核验记录见数据目录，正式方法与限制见当前报告附录。
