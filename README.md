# 中国义务教育生源规模与财政投入趋势分析（1994—2024）

**见数知势队｜研究数据与分析材料仓库**

本仓库配套《中国义务教育生源规模与财政投入趋势分析报告（1994—2024）》，集中保存报告所用的整理数据、分析代码、计算结果、统计图示及资料核查记录，供读者**查找数据、追溯来源、复核结果和复用图表**。



## 仓库有什么

| 内容 | 说明 |
| --- | --- |
| 数据 | 全国与省级数据、原值账本、核准及重建结果、模型输入和输出 |
| 代码 | 数据抽取、整理、计算、检验及制图程序 |
| 图表 | 报告采用的18幅图示，提供PNG、PDF、SVG及对应绘图数据 |
| 研究记录 | 各阶段的资料说明、核查记录、分析方案与历史探索材料 |
| 来源与校验 | 原始资料索引、文件清单、SHA-256散列及仓库核验工具 |

各阶段文件予以保留，以便追溯研究过程。**查找当前采用的版本，请以正式索引为准，不要仅根据目录日期或文件名判断。**

## 如何使用

阅读或引用材料时，建议先通过[数据索引](research/DATA_INDEX.md)定位相应文件；使用报告图表时，通过[图表索引](visualizations/FIGURE_INDEX.md)找到对应格式、绘图数据和程序。需要追溯原始资料时，可查阅[来源记录](provenance/README.md)。

如需在本地核验仓库，使用Python 3.12及以上版本，在仓库根目录运行：

```bash
python -m pip install -r requirements.txt
python tools/verify_release.py
python tools/verify_repository.py
python tools/check_key_findings.py
```

三项检查分别用于文件完整性、目录及图表对应关系、关键统计结果复核；**不等同于从全部原始年鉴重新运行完整研究**。两份以gzip保存的大型原值CSV可按需运行 `python tools/materialize_data.py` 恢复。重新执行分析和制图程序前，建议先使用仓库副本，以免覆盖已有阶段输出。

## 使用说明

全国在校生资料覆盖1995—2024年；经费序列以1994年的条件估算补充历史基期。不同分析使用的时间窗口、统计范围和选用版本，请参见各自的数据索引与记录。

第三方整本年鉴、论文全文、扫描件及字体未随本仓库重新分发；对应来源和获取线索见[来源与追溯说明](provenance/README.md)。引用原始统计数据时应注明原始来源；引用本仓库的整理数据、代码或图示，可使用[引用信息](CITATION.cff)。仓库目前未为自编代码与衍生材料单独指定开放许可证。
