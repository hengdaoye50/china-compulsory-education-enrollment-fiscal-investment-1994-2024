# 中国义务教育生源规模与财政投入趋势分析（1994—2024）

**Chinese Compulsory Education Enrollment and Fiscal Investment Trends 1994–2024**

本仓库仅发布见数知势队研究的数据与数据分析材料，包括整理数据、原值账本、来源与核查记录、统计代码、计算结果、绘图数据和可视化图示。主体观察期为1995—2024年，1994年为单独标记的条件估算补充基期。

## 目录与分析入口

- `教育资源试做/data/`：数据系列、原值账本、清洗和口径核查、分析方案与统计结果。
- `教育资源试做/converted/`：机器可读年鉴表格及原表抽取材料。
- `教育资源试做/scripts/`：资料抽取、数据处理、核查、统计分析和制图程序。
- `visualizations/`：长期趋势、地区比较、统计区间及举办者构成分解的图示和绘图数据。
- `教育资源试做/正式学术图组_20261011/`及其他有日期的图组：原始分析图示、图注与绘图数据；图号在所属图组内解释。
- `provenance/`：文件清单、SHA-256、外部原件索引与公开范围记录。
- `tools/`：文件完整性验证、压缩数据恢复、关键统计结果复核及图3制图程序。

全国生源和下降轮次见`data/三十年纵向分析_20261010/`；全国经费采用`data/早期财政重建_20261011/national_fiscal_1994_2024_report_final.csv`。文件名中的report_final表示此前确定的数据选用版本，不是报告正文。直接差模型和推断结果见`data/定量深化_20261011/`、`data/支出细项与补助拓展_20261011/`；资源拓展见`data/资源解释拓展_20261011/`。后续原表核查见`data/经费断点再核查_20261012/`。

## 方法与数据状态

保留数据口径说明、拟合前分析方案、计算核验与图注，便于复核。候选账本与核准数据分开；candidate或范围待核标记不能理解为最终核准。1994年估算不进入回归，情景范围不是置信区间。财政性收入与学校全来源支出分别解释，生源与财务覆盖未完全对应，不计算严格同范围生均支出。

实际变化使用地区CPI近似调整。省级模型属于探索性条件关联，保留未获支持的假设和敏感性结果，不用于认定政策净效应或独立机制。

## 复核与运行

创建独立Python环境，按requirements.txt安装依赖。两份较大的原值CSV无损压缩为gzip；执行：

```bash
python tools/verify_release.py
python tools/materialize_data.py
python tools/check_key_findings.py
```

按阶段查看分析与制图程序，例如：

```bash
python 教育资源试做/scripts/deepen_quantitative_analysis.py
python 教育资源试做/scripts/check_component_regime_sensitivity.py
python 教育资源试做/scripts/build_revised_figures.py
```

分析程序可能包含9999次自助检验，并重新写入阶段输出。制图脚本的中文字体路径需要根据运行环境替换。原表抽取需依来源索引获取外部原件。完整性与关键结果复核不等于完成从所有原始年鉴到全部结果的跨环境全流程复跑。

## 公开范围

仓库当前版本不包含正式或历史报告正文、章节草稿、Word报告、报告PDF及写作排版材料。PDF格式的统计图和图组属于分析可视化，予以保留。

第三方年鉴整本文件、论文全文、扫描页及字体不随包分发，原件保留来源索引和获取说明。统计数据应引用原始年鉴和官方机构；自编代码尚未另行指定开放许可。
