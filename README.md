# 中国义务教育生源规模与财政投入趋势分析（1994—2024）

**Chinese Compulsory Education Enrollment and Fiscal Investment Trends, 1994–2024**

见数知势队整理的研究数据、分析代码、计算结果和统计图示。研究关注三个相互关联的问题：小学与初中的生源规模如何变化，教育投入扩张如何体现为地区和支出结构差异，不同支出项目如何与区域生源变化相联系。

全国生源系列覆盖1995—2024年；经费系列以1994年条件估算补充历史基期。省级比较和回归分别采用经过核查的可用窗口，具体年份、观察数与纳入规则随结果一并保存。

数据子目录中的日期标识研究阶段。例如，`早期财政重建_20261011`保存早期经费重建，`经费断点再核查_20261012`保存其后的分类与单位核查。日期较新并不表示自动替代全部较早成果；选用版本以数据索引为准。

`visualizations/FIGURE_INDEX.md`是当前图示入口。`research/figures/`保留专题分析图组和部分历史数据；图组内的`fig04`、`图F3`等名称是阶段编号，统一图号由图表索引对应。PNG用于阅读和文档插图，PDF、SVG用于矢量输出。

## 数据与方法

- **资料来源**：教育统计年鉴、教育经费统计年鉴，以及教育部、国家统计局和地方官方材料。原值账本保留表格位置、单位、来源和核查状态。
- **长期趋势**：全国在校生、财政性收入金额及占比；地方隶属学校的个人、公用及内部项目支出。收入与支出按各自统计定义组织。
- **构成分解**：采用中点恒等式分解举办者收入权重与组内财政性比例的贡献；以同省前期公用金额为分母计算商品服务和其他资本性项目的增长贡献。
- **省级分析**：使用实际对数变化、省份与年份固定效应，以及支出项目之间的直接差模型；相关检验保留聚类推断、Holm校正、剔除年份和分期结果。
- **价格调整**：地区实际变化采用地区CPI；这是一般价格调整，教育专属成本变化是另一个研究对象。

1994年标记为条件估算，1995—1997年经费按支出来源重建，后续年份按收入来源整理。`status`、`accounting`等字段标识数据状态与会计口径，早期情景范围描述分配假设的变化。候选数据、核准值、探索结果和敏感性结果均保留其身份，便于追溯选用过程。研究呈现长期趋势、账面构成和省级条件关联。

## 复核与复现

以下命令均在仓库根目录运行，采用Python 3.12或更高版本及独立环境，以满足已记录的依赖版本。安装分析依赖：

```bash
python -m pip install -r requirements.txt
```

**文件与关键结果复核**：

```bash
python tools/verify_release.py
python tools/verify_repository.py
python tools/check_key_findings.py
```

第一项核验文件散列和压缩数据的逻辑内容；第二项检查目录、索引链接、程序语法和临时文件；第三项独立复算全国生源峰谷、经费增长、主要直接差系数及项目贡献恒等式。关键结果复核读取已保存的自助检验p值，自助抽样另由分析程序执行。

**恢复两份较大的原值CSV**：

```bash
python tools/materialize_data.py
```

仓库采用gzip无损存储`education_finance_original_candidates.csv`和`raw_value_ledger.csv`；恢复后可供相关抽取与核查程序读取，解压副本由Git忽略。

**分阶段重新分析或制图**：

| 工作 | 程序 |
| --- | --- |
| 个人与公用支出的直接差分析 | `research/scripts/deepen_quantitative_analysis.py` |
| 支出细项及中央补助拓展 | `research/scripts/analyze_spending_components_subsidies.py` |
| 追加分类年份与分期敏感性分析 | `research/scripts/check_component_regime_sensitivity.py` |
| 资源变量拓展 | `research/scripts/extend_resource_explanations.py` |
| 趋势、地图及地区统计图重绘 | `research/scripts/build_revised_figures.py` |
| 单独重绘举办者构成分解 | `tools/replot_fig3_20261012.py` |

分析程序会重写所属阶段的输出，自助检验可能包含9,999次抽样，建议在仓库副本中执行。部分历史制图程序使用Windows中文字体路径，跨平台运行时请替换为本机中文字体；图3制图支持`MPL_CJK_FONT`环境变量。从年鉴重新抽取还需按来源索引补齐外部原件。已有文件核验和关键结果复算的执行记录见[仓库核验记录](provenance/repository_audit_20261012.json)。
