# 定量深化：拟合前分析方案

记录日期：2026年10月11日。本轮为既有研究后的探索性扩展，不是预注册或确认性检验；此前 H1/H2 的弱证据不得删除。

问题：在控制省份长期差异与年度共同变化后，个人支出、公用支出对区域学生规模变化和地方自身财政收入变化的响应是否不同？这比仅描述经费与学生反向变化更接近原研究中的“总量保障与内部调整”问题。

主窗口为2008—2023年，2007年仅为基期；不跨2006→2007经费分类转换。分别使用小学、初中既有年度变化表，保留全部数值完整省年，不依据学生或支出是否下降筛样本，不插值、不缩尾。研究历史窗口仍为1995—2024年，1994条件估算只用于历史补充，不进入回归。

P/C 是全隶属、全来源支出的个人/公用分类，不等于政府预算支出、纯工资或纯日常运行经费；学生覆盖尚未完全桥接，只解释区域生源背景，不估计生均投入或严格需求弹性。R为地方自身财政收入，不代表补助后的全部可用财力。使用省级CPI对金额变化作近似购买力调整。

主模型按学段分别估计：Δln支出 = βS×Δln学生 + βR×Δln实际自身收入 + 省份固定效应 + 年份固定效应 + 误差。支出结果分别为P、C；直接差异模型因变量为D=ΔlnC−ΔlnP，相同样本及设计下系数必须等于C模型减P模型。

主检验族为两个学段各自D模型的βS、βR，共4项。省份聚类CR1标准误；采用既有零假设约束野生聚类自助9999次、同一检验反演95%置信集，固定种子；4项p值作Holm校正。报告区间是否分离、搜索边界是否未封闭，不以搜索边界假冒无穷大。P/C分模型图展示聚类CR1标准误的正态近似95%区间，不能和野生自助主推断混称。

预定敏感性：剔除2015/2016财政分类转换附近变化；剔除2020—2022；剔除直辖市；固定28省级地区（除四川、重庆、西藏）；剔除2013/2014学校与支出范围边界附近变化；收入使用名义变化作为共同物价误差对照；分别逐省、逐年删除。均完整报告点估计与CR1标准误，不择优。

补充模型：学生增长max(dS,0)与下降幅度max(-dS,0)分开进入；对D只报告探索点估计和CR1标准误，不追加主检验。加入当期及一期滞后学生/自身收入变化，滞后必须是相邻日历年，检验累计响应只作敏感性而不宣称动态因果。补充模型不能替代未通过的主结果。

无因果识别设计：财政、学生与经费可能共同内生，固定效应不消除随时间变化的遗漏因素；按省聚类不完全解决跨省相关。不能称为政策效果、改革成败、支出效率或中介机制检验。
