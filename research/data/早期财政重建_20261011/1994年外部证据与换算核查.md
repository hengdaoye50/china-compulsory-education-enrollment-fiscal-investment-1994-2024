# 1994年教育经费：外部证据与换算核查

核查日期：2026年10月11日。目的：寻找当年可用于换算的资料，检验此前小学399.92亿元、初中258.56亿元的暂估。金额均按名义价格，不作物价调整。

## 核查结论

找到可用的1994年全国经费来源构成、义务教育预算拨款比例和分学段生均预算内事业费。新增两套换算，小学财政性支出分别为398.39亿元、399.27亿元，初中分别为256.79亿元、257.35亿元。它们借用1995年分配比例，属于有当年来源锚点的条件估算，不能升级为分学段实测值。

官方白皮书确实记载小学经费594亿元。来源存在已经核实，统计范围差异尚未解决。因此不能把594亿元简单删除，也不能把它当成财政性支出。现有长表和正式图中的原暂估保留，新增结果作为敏感性核查。主报告1995—2024年30年的观察资料不受影响。

## 当年可用的资料

1. [国家统计局《中国统计年鉴2001》20-36表](https://www.stats.gov.cn/sj/ndsj/2001c/t2036c.htm)：1994年全国总经费14887812.6万元，财政性经费11747395.6万元，预算内经费8839794.7万元；另有社会及个人办学、捐集资、学杂费、其他经费的全国总额。该表保留一位万元小数，是本次来源拆分的数值锚点。
2. [1994年全国教育经费执行情况统计公告](https://www.edu.cn/edu/tjsj/zhsj/jiao_yu_jing_fei/200603/t20060323_11713.shtml)：小学、初中生均预算内教育事业费为236.06元、450.37元。它们只对应预算内事业费，并非总经费或全部财政性经费。将生均指标乘人数时，必须匹配财政统计的举办者范围和年度平均人数，不能直接使用全部学校年末在校生数。
3. [《中国教育经费投入的“八五”回顾与“九五”展望》](https://www.cnsaes.org.cn/homepage/Upfile/2010612/2010061208642783.pdf)：脚注注明系1996年撰写的教育经费年度报告部分内容。PDF第5页表1-4给出1994年义务教育占预算拨款比例53.41%；包含小学、初中及特殊教育。由此换算的预算内义务教育拨款约472.13亿元，是乘算结果，不是分学段观察金额。该资料通过网页PDF文本提取核查；本次未成功取得页面截图，原始版面审校尚未完成。
4. [国务院新闻办公室白皮书《中国的儿童状况》，外交部转载](https://www.fmprc.gov.cn/ziliao_674904/zt_674979/ywzt_675099/wzzt_675579/2296_675789/200207/t20020705_7961975.shtml)：小学总经费594亿元，普通中学435亿元。普通中学包括高中，435亿元不能当作初中经费。白皮书未给出小学财政性来源分项。

## 换算一：按当年六类来源分别分配

将全国来源分为预算内、其他财政性、社会及个人办学、捐集资、学杂费、其他非财政性六类。其他财政性由全国财政性减预算内计算，避免重复计入。每一来源分别使用1995年同学段占全国该来源的比例：

`估计C(学段,1994) = 全国C(1994) × 实测C(学段,1995) / 实测全国C(1995)`

`估计财政性 = 估计预算内 + 估计其他财政性`

`估计总经费 = 六类来源估计值之和`

这比对财政性和总额各乘一个总比例多利用了1994年的来源结构，但仍假设各来源的学段分配接近1995年。源别拆分不是六个独立的实测学段数值。

| 全国1994年锚点 | 亿元 |
|---|---:|
| 预算内 | 883.97947 |
| 其他财政性 | 290.76009 |
| 社会及个人办学 | 10.77952 |
| 捐集资 | 97.44871 |
| 学杂费 | 146.92281 |
| 其他非财政性 | 58.89066 |
| 总经费 | 1488.78126 |

全国六类之和精确等于官方总经费，前两类之和精确等于财政性经费。1995—1997年各类分学段来源来自本项目已有年鉴原表证据；原始散列值见source_evidence.json，计算明细见1994_conversion_components.csv。

## 换算二：加入当年义务教育预算比例约束

先求 `883.97947 × 53.41% = 472.13343亿元`，再按1995年小学、初中、特殊教育预算内支出之间的比例分配这项预算总额。其他五类来源沿用换算一。

必须把特殊教育保留在分配分母中，不能把义务教育合计全部分给小学和初中。53.41%为舍入后的年度报告数值，且其文字叙述与个别表格金额存在微小不一致；所以本方案是约束情景，不是精确会计重建。项目原表算出的1995年义务教育预算份额为53.24609%，该报告表列53.24%，差0.00609个百分点；不能声称二者完全一致。

| 换算方法，以1995年为分配依据 | 小学财政性（亿元） | 初中财政性（亿元） | 小学总经费（亿元） | 初中总经费（亿元） |
|---|---:|---:|---:|---:|
| 此前按财政性和总额分别回推 | 399.92 | 258.56 | 505.37 | 331.68 |
| 按六类来源分别分配 | 398.39 | 256.79 | 501.06 | 326.99 |
| 加入1994年义务教育预算比例 | 399.27 | 257.35 | 501.95 | 327.55 |

新方案的财政性金额与此前暂估均相差不到1%。这说明原估计在所测试的分配假设下较稳定，但方案共用1995年分配数据，不能称为独立验证，更不能证明1994年真实误差不到1%。

## 敏感性和回测

另用1996年、1997年比例运行两套新方法，共12条情景，见1994_conversion_scenarios.csv。新方法的财政性情景范围为小学397.60—401.75亿元、初中256.79—264.64亿元；此前方法的范围另行保留。情景范围不是统计置信区间，未包含594亿元口径冲突造成的误差。

对换算一，用1996年来源分配比例回推1995年、1997年比例回推1996年，财政性金额误差：小学+0.86%、−0.26%，初中+3.08%、−1.39%。每学段只有两个回测，不能据此推断1994年的精度或误差上限。回测见1994_component_backtests.csv。

## 594亿元如何处理

594亿元比新约束方案小学总额501.95亿元高约18.34%。这属于总经费与总经费之间的不一致，不是把594直接与399.27财政性支出相比。白皮书没有提供足够的来源分项来解释差额。

假如条件性地把594亿元当作同范围总额，再乘1995年小学财政性占比，可得约447.76亿元。但该换算既假定总额口径一致，又假定财政性占比稳定，不能用来宣称已经落实1994年财政性金额，也未纳入本次推荐情景。需要原始1994年分学段来源表或白皮书统计范围说明才能解决。

另查到李人庆2003年研究报告的网络存档列有1994年义务教育投入表。其全国总经费为14166398万元，与官方14887812.6万元不同；表中多处数值存在疑似小数点丢失。原站本次不可达，故仅作为继续寻找原表的线索，不将该网页数值混入正式换算。详情见1994_external_source_ledger.json。

## 对正式报告的处理决定

在本次核查完成时，1994年保留为前置估算补充，主图原暂估暂时保留。随后用户授权补入最终数据并制作正式报告，最终选择加入义务教育预算比例约束的方案：小学财政性399.27亿元、初中257.35亿元，正式图2与长表已经同步。新范围限定为该方案1995—1997年分配比例情景；旧回推长表及原方法记录保留，不把不同方法的范围混称为同一个置信区间。不计算1994—1995年的精确同比，不以1994年估算点判断历史转折。1995—2024年仍是本研究的30年主体。最终选择见report_final_selection.json。

本次新增资料可以实质加强换算依据，但没有取得1994年小学、初中财政性经费的完整原始分项表，范围冲突也未消失。下一项最有价值的资料是《中国教育经费统计年鉴1995》全国分学段来源表，或1991—1995年教育经费年度发展报告的分学段原表。

外部核查计算由check_1994_finance_sources.py复算，保护原回推长表内容散列值；最终选择由finalize_report_finance.py另存报告长表，未改原始数据。所有新增CSV、JSON和本说明纳入本地复现交付包。
