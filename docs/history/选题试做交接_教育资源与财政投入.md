## 2. 初步问题与竞争解释

暂定主问题：学生规模从增长转向收缩时，教师、班级、学校及教育经费是否以不同速度调整？不同财政条件的地区是否呈现不同调整路径？

优先观察普通小学，若数据支持，再用普通初中比较学段差异。不预设“调整慢就是低效”或“学生减少就应撤校减师”。

待区分的解释：
- 基本保障：需求收缩时维持资源，有助于小班教学和基本就学保障。
- 资源调整存在滞后：需求已经变化，部分供给仍沿此前路径变化。
- 生均指标改善主要源于学生分母减少，而非投入增长。
- 财政约束与上级补助共同影响支出调整，不能只用本地收入解释。

现有数据可以先识别变化与关联；没有政策冲击、比较组和识别依据时，不开展或包装DID等因果评估。资源数量和财政投入不能自动代表教学质量、通学便利或学生福利。
