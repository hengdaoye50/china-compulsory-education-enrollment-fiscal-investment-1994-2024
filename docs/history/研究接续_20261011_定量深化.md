# 研究接续 2026年10月11日定量深化

用户判断描述分析可能偏表面，要求回到原设计、强化问题意识并进一步跑回归和可视化。本轮已完成一项完整的探索扩展，不是仅提出计划。

问题为：长期总量保障背景下，公用和个人支出对区域生源、自身收入变化是否具有不同条件响应？先记录拟合前方案，再用2008—2023年全部完整省年（每学段472条、31省级地区），不只挑持续收缩，不按支出结果筛选。历史研究仍是1995—2024年，1994条件估算不入回归。

## 必须保留的结论与限制

初中学生响应差0.601，单项95%WCR区间[0.229,0.982]、Holm p=.0144。小学0.695、Holm p=.0879。自身收入差小学0.217、初中0.164，区间跨零，Holm p=.1388/.1884；初中收入差删2015/2016降至.025，应重点注意定义边界。

初中学生差逐省删除.528—.701，逐年删除.439—.746；预定样本敏感性.506—.671。相邻年滞后模型初中学生累计.459（CR1 SE .203），小学1.054（.350）。下降幅度单独进入时初中D系数−.462、SE .275，正态近似区间跨零：平均线性结果不能宣布专门的学生收缩效应成立。两学段各自p差异也不是学段差异检验。

P/C为全隶属、全来源个人/公用分类，非纯工资/纯运行/财政预算。学生范围尚未完全桥接，R为自身收入而非补助后全部财力；原model_scope_approved=False保留，探索结果不代表最终口径核准。固定效应不是因果识别；不将弱证据旧H1/H2删除，不声称政策效果或效率。

最有价值的后续：先核准转移支付、教师/学校/班级存量，再设计与固定成本、人员存量约束、财力补助等竞争解释相对应的模型。不要把可能位于调整路径中的变量机械放入所有主模型。原长期历史图作为背景，直接差与分项图进入主文，散点及敏感性进入附录。

## 运行环境与复现注意

使用Codex bundled Python，以`-X utf8`运行。Matplotlib依赖位于`教育资源试做/.tmp/figure_deps`；模型脚本自动设置OPENBLAS/OMP单线程。新脚本的MPLCONFIGDIR写在工作区，避免用户级缓存写入限制。文档渲染时将TEMP/TMP设为工作区`教育资源试做/.tmp/quant_doc_render`，再调用documents技能render_docx.py；默认沙盒系统临时目录写入会失败。LibreOffice中文输出可能造成读取线程UnicodeDecodeError，但退出0并真实产出4页PDF/PNG；已以文件和逐页图像验收，不只看退出码。
